# 章节事实与状态投影

## 只观察明确变化

只抽取本章真正建立的东西：人物行动与身体状态、地点、资源、关系变化、情绪、信息边界、情节承诺、时间推进、在场人物。宁要精确事实，不要抽象总结。暗示可以留成未解决的叙事承诺，但它不是已完成事件。

## 增量投影

在给定运行状态上更新，而不是从头重建。保住无关事实与稳定 id。人物认知以他亲眼所见或被人告知的范围为界。章节停在门槛前，状态就不能把人物推过门槛。大纲是规划上下文，不是事件发生过的证据。

## 伏笔身份与生命周期

- 同一未解决承诺换了措辞、名字、数字、证据形态或措辞时，仍复用原伏笔 id。
- **提及**只是重复或召回，不改变事实、风险、范围、关系或理解，不推进 `lastAdvancedChapter`。
- **推进**要增加证据、改变风险或范围、改变关系，或改变读者／人物能得出的结论。
- **兑现**只在章节回答或否证该承诺时；**延后**只在故事明确把它移到背景时。
- 当前已确认的基础设定或范围内的修订**明确撤回**某承诺的前提时，把该伏笔更新为 `superseded`，并在 notes 里注明撤回依据；保住 id、原始前提与历史推进。这是撤销规划，不是正文兑现或延期。不要因为本章没出现某伏笔就推断撤回；不要撤回已兑现的历史。`superseded` 条目是存档记录，不是活跃承诺，也不是必须发生的未来事件。
- 只有当没有任何现存伏笔代表这个新承诺时，才新建候选；兑付时距用 `immediate`、`near-term`、`mid-arc`、`slow-burn`、`endgame` 之一。

## 数值与人物状态

存在资源系统时，每一笔明确增减都要对得上：期初值 + 变化 = 期末值。开启全阵容追踪时，记录在场人物、被提及的缺席人物、关系变化与信息边界。
